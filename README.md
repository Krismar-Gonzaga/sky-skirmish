# Sky Skirmish

A 2D side-view jetpack shooter for Android, built with Godot 4 for ITSD 85, Laboratory 5. Clear a 10-level campaign against bots, or fight another player 1 vs 1 over local Wi-Fi or the internet.

The game uses its own name, characters, maps and art. All art and sound are generated by the project's code, so it builds with no downloads.

## What is in it

- **Campaign:** 10 levels on 3 maps, with tutorial, eliminate, survive, capture, boss and gauntlet missions. Clearing a level unlocks the next, and progress survives closing the app.
- **Local multiplayer:** two phones on the same Wi-Fi or a phone's hotspot, with no internet.
- **Online multiplayer:** two phones anywhere, joined by a 6-character room code through a small relay server.
- **Tuning for playtests:** weapons, levels, bots and physics are all JSON files in `data/`. Press F3 or tap with three fingers for the debug overlay.

## Run it

1. Install [Godot 4.7](https://godotengine.org/download) or a newer 4.x release.
2. Open this folder in the Godot editor.
3. Press F5.

Desktop controls: A/D walk, W or Space jet, S crouch, mouse aims, left click fires, G grenade, Q swap, F melee, Esc pause.

To build the Android APK, follow [docs/BUILD.md](docs/BUILD.md).

## Test it

From Git Bash on Windows, or a terminal elsewhere:

```
cp tools/local.env.example tools/local.env   # then set your Godot path, if godot is not on PATH
bash tools/run_tests.sh
```

This runs a parse and warning check, the unit and integration tests, real two-process network tests over ENet and a local relay, and the relay's own tests. It takes about 4 minutes.

Results against the design's test cases are in [docs/TEST_REPORT.md](docs/TEST_REPORT.md).

## Try multiplayer on one PC

```
bash tools/run_local_mp.sh
```

This opens two windows and starts a LAN match between them. For online play on one PC, see the end of [docs/RELAY_DEPLOY.md](docs/RELAY_DEPLOY.md).

## Developer flags

Put these after `--`, for example `godot --path . -- --level=3 --unlock-all`.

| Flag | Effect |
| --- | --- |
| `--level=<n>` | Start a campaign level straight away |
| `--unlock-all` | Open every level for this session, without saving it |
| `--touch` | Use the on-screen controls with a mouse |
| `--host` | Host a LAN match and start when someone joins |
| `--join=<ip>` | Join a LAN match |
| `--relay=<url>` | Use this relay; with `--host`, create a room |
| `--room=<code>` | With `--relay`, join this room |
| `--profile=<name>` | Use a separate save, for running two copies |

## Project layout

| Folder | Contents |
| --- | --- |
| `autoload/` | GameState, LevelManager, ProgressService, NetworkManager, AudioManager, Settings |
| `scenes/` | Screens, match, fighters and maps |
| `scripts/` | Game code, grouped by area: core, input, player, weapons, bots, missions, game, net, ui |
| `data/` | Tuning, weapons, levels, difficulty, credits and map layouts |
| `assets/` | `asset_map.json`, the single place visuals and sounds are chosen, plus theme, shaders and icons |
| `server/` | The Node.js relay and its tests |
| `tests/` | GUT tests and two-process network scenarios |
| `tools/` | Test, export and benchmark scripts |
| `docs/` | Design, build, relay, test report, playtest form, change log, credits, demo script |

To replace placeholder art, set a `texture` path in `assets/asset_map.json`. No code needs to change. Credit every added asset in `docs/CREDITS.md` and `data/credits.json`.
