# Demo video script (2 minutes 45 seconds)

The video must show a level unlock, an offline LAN match and an online match.

## Prepare first

- Install the same APK on both phones, with `relay_url` set in the build.
- Clear the app's data on phone A, or reinstall it, so only Level 1 is open.
- Open the relay's `/health` page a minute before filming, so the server is awake.
- Practise Level 1 so you can clear it quickly.
- Film the phones with a third camera, or record each screen and cut between them.

## Script

| Time | Show | Say |
| --- | --- | --- |
| 0:00 | Main Menu on phone A | "This is Sky Skirmish, a jetpack shooter for Android, built with Godot for ITSD 85." |
| 0:10 | Level Select | "The campaign has 10 levels. Only Level 1 is open on a fresh install." |
| 0:18 | Tap the locked Level 2 | "Locked levels tell you what to clear first." |
| 0:25 | Start Level 1. Walk, fly, shoot the three dummies | "Two thumbs: the left stick moves and flies, the right stick aims and fires." |
| 0:50 | Level Results, with stars and "Level 2 unlocked!" | "Clearing a level earns stars and unlocks the next one." |
| 0:58 | Close the app fully, reopen, open Level Select | "Progress is saved on the phone, so Level 2 is still open after a restart." |
| 1:10 | Phone A: turn on hotspot, data off. Phone B: join it | "Now offline play. Phone B joins phone A's hotspot, with no internet at all." |
| 1:20 | Phone A: Multiplayer, Local, Host, showing the address. Phone B: Join | "One phone hosts. The other finds it on the network, or types its address." |
| 1:30 | Start, and show a few kills on both phones | "The host runs the match, and the other phone sends its input." |
| 1:50 | Both phones: Wi-Fi off, on mobile data. Multiplayer, Online, Create Room | "Now online, over mobile data. Phone A creates a room and gets a code." |
| 2:00 | Phone B types the code. Start | "Phone B types the code, and a free relay server connects the two." |
| 2:12 | Show a few kills | "It is the same game code as local play. Only the connection changes." |
| 2:25 | Match Results, then Credits | "The winner is decided by kills. Every asset and tool is credited in the game." |
| 2:35 | Title screen | "Built with free tools at no cost, and improved through structured playtests. Thank you." |

## If something goes wrong

- If the online step shows "Waking server…", keep filming or cut. It can take up to a minute.
- If the phones do not find each other on the hotspot, type the host's address. Say so; it is a designed fallback, because some phones block broadcasts.
